# GameHub

Repo da duoc sap xep theo cau truc monorepo trong `gamehub/`.

## Chay GameHub

```bash
npm start
```

Mo:

```text
http://localhost:3000
```

Luong chinh:

- Tao phong trong GameHub de nhan ma phong va owner token.
- Chu phong chon game, mo game va quan ly setting cua game.
- Nguoi choi nhap ten va ma phong de vao phong.
- Moi game giu setting rieng; diem duoc luu theo tung game trong room state va reset khi chu phong bat dau/chuyen sang game moi.

## Chay Rieng Ma Soi

```bash
npm run start:werewolves
```

Game con nam tai:

```text
gamehub/games/werewolves
```
